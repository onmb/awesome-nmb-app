## 客户端列表

### nmbxd.rs
- 仓库：https://github.com/karuboniru/nmbxd.rs
- 帖子: https://www.nmbxd1.com/t/69666266
- 类型：Linux GUI 岛客户端（纯 vibe 产物，整体仍在施工中）
- 当前状态：基本可用，已支持基本浏览和文字回复
- 已知情况：
  - A 岛特色功能还未实现（例如颜文字）
  - 目前仅测试 Linux，理论上可在 Windows / macOS 构建，但暂未验证
  - 饼干需要手动从浏览器复制 raw string
